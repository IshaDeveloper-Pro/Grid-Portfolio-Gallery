# 🖼️ Interactive Grid Portfolio Gallery

A modern, visually stunning photo gallery and portfolio showcase built using HTML5 and CSS3 Grid, featuring smooth hover effects and responsive design.

## ✨ Features
* **CSS Grid Layout:** Designed with a sophisticated multi-image layout showcasing nature categories (Waterfalls, Ocean, Mountains, Trees, Beach, etc.).
* **Smooth Hover Effects:** Interactive card transitions and visual transformations on mouse hover.
* **Fully Responsive:** Adapts seamlessly across various desktop and mobile screen sizes.
* **Modern Typography:** Clean, elegant font styling paired with a sleek dark theme.

## 🛠️ Tech Stack
* **HTML5:** Semantic markup structure.
* **CSS3:** CSS Grid, Flexbox, custom media queries, and transition effects.
